How it works

  1. Type a romanized word, like konnichiwa. It converts live, with no candidates to pick.
  2. ん: type n. If a vowel follows, it waits to see whether you meant a different syllable: kinen becomes 「きねん」. If you really want ん before a vowel, add an apostrophe: kin'en gives 「きんえん」. If n is the last letter you type in a word, it stays shown as an underlined n until you press space or Enter to confirm; that's the moment it becomes ん.
  3. っ (small tsu): double the next consonant, e.g. kekkon is 「けっこん」; typing it once as kekon gives 「けこん」instead.
  4. Long vowels: repeat the vowel letter, e.g. okaasan is 「おかあさん」. For the katakana-style long-vowel mark, type a hyphen: ke-ki gives 「ケーキ」.
  5. Use the buttons above to switch between hiragana and katakana display anytime; your romaji doesn't change.
  6. Press space or Enter to confirm, then copy and paste wherever you need it.

Current limitations

The small っ only recognizes a doubled identical consonant: for 「まっちゃ」type the doubled-c spelling maccha. Typing matcha won't insert っ automatically. Everything you type stays in your browser, and nothing is sent to a server.

FAQ

Do I need to install anything to use this Japanese keyboard?

No. It's a web tool: open the page and start typing. There's no system input method to switch.

How is this different from the Japanese IME built into my phone or computer?

The typing rules are nearly identical: romaji converted to kana. The difference is you don't need to switch on or enable a Japanese input method first, which matters when you're on someone else's computer or your system doesn't have one ready.

How do I type ん?

Type n. If a vowel follows, it waits to see whether you meant a different syllable (kinen becomes きねん). If you really want ん before a vowel, add an apostrophe: kin'en gives きんえん. If n is the last letter you type in a word, it stays shown as an underlined n until you press space or Enter to confirm; that's the moment it becomes ん.

How do I type the small っ?

Double the next consonant: kekkon is けっこん. Typing it once, as kekon, gives けこん instead. It only recognizes a doubled identical consonant, so まっちゃ needs the doubled-c spelling maccha; typing matcha won't insert っ automatically.

If I switch between hiragana and katakana, does it change what I've already typed?

No. The buttons only switch how it's displayed. They don't touch your romaji or anything already confirmed, so switching anytime is safe.

Why I built this

After the Korean keyboard problem was solved, Japanese was next: phones and computers already have a built-in romaji input method, but it isn't always ready right when you need it, say on someone else's computer, or for a quick one-off word. This version reuses the same underlying engine.
