How it works

  1. Type a romanized word, like annyeonghaseyo.
  2. When a word is ambiguous, a candidate list pops up below it: press ↓ to cycle, or press 1/2/3 to jump directly. To force a specific split, capitalize the first letter of the next syllable: gaEul always splits into 가 + 을, and it's faster to type than a hyphen. A hyphen (ga-eul) works the same way if you prefer it.
  3. Press space or Enter to confirm, then copy and paste wherever you need it.

Current limitations

Default accuracy is roughly 80%. When it picks the wrong reading, press ↓ to choose the right candidate. Everything you type stays in your browser, and nothing is sent to a server.

FAQ

Do I need to install anything to use this Korean keyboard?

No. It's a web tool: open the page and start typing. No Korean IME to install, no system keyboard to switch.

How is this different from installing a 두벌식 Korean keyboard layout?

두벌식 means memorizing where each letter sits on the keyboard: d for ㅇ, k for ㅏ, and so on. This tool uses the romanization you already know instead. Type annyeong and get 안녕, no new layout to learn.

Do I type by pronunciation or by spelling?

By spelling. "Thank you" is typed gamsahabnida, not the way it sounds (gamsahamnida). The most common gap, nasalization at the end of polite verb endings like -습니다/-ㅂ니다, is handled: type gamsahamnida and 감사합니다 will usually still turn up as a candidate, press ↓ to pick it. Other sound changes, like liaison or palatalization, aren't covered yet, so those still need correct spelling.

Can it type names or new words that aren't in any dictionary?

Yes. This isn't a dictionary lookup. It builds syllables straight from Hangul spelling rules, so any valid romanization works, including names, places, and words no dictionary has caught up with yet.

Can I type Korean with romanization on my phone?

The page works on mobile, but candidate switching is built around keyboard arrow keys, so typing on a phone hasn't been optimized yet.

Why I built this

Typing Korean on a computer is a common wall for beginners: 두벌식 means memorizing where every letter sits on the keyboard, and early on, looking things up one character at a time is painfully slow. This tool lets you type the romanization you already know instead of learning a new keyboard layout.
