Type Korean with Roman Letters

Type the romanization you already know and it converts to Korean automatically — no keyboard layout to memorize.

Type by spelling, not by pronunciation: johayo joayo

Try it:

How it works

  1. Type a romanized word, like annyeonghaseyo.
  2. When a word is ambiguous, a candidate list pops up below it: press ↓ to cycle, or press 1/2/3 to jump directly. To force a specific split, capitalize the first letter of the next syllable — gaEul always splits into 가 + 을, and it's faster to type than a hyphen. A hyphen (ga-eul) works the same way if you prefer it.
  3. Press space or Enter to confirm, then copy and paste wherever you need it.

Current limitations

Default accuracy is roughly 80%. When it picks the wrong reading, press ↓ to choose the right candidate. Everything you type stays in your browser — nothing is sent to a server.
