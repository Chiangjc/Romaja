How to type

  1. Match the diagram above and type on your real keyboard — not romanization, the actual key shown in the diagram.
  2. The doubled consonants (ㄲㄸㅃㅆㅉ) and vowels (ㅒㅖ) need Shift held down, e.g. Shift+R for ㄲ.
  3. Every key maps to exactly one letter — no candidates to pick. The tool figures out syllable boundaries automatically as you type; press space between words, then copy the result.

Current limits

Dubeolsik is a fixed key mapping, so unlike the romanization keyboard there's no candidate list to rescue a mistyped word — backspace and retype instead. Your text stays in your browser and is never sent to a server.

FAQ

Do I need to install anything to use this dubeolsik keyboard?

No. It's a web tool — open the page and type on your real keyboard. No Korean IME to install, no system keyboard to switch.

How is this different from the romanization keyboard?

Dubeolsik is South Korea's official layout: every physical key maps to one fixed consonant or vowel, so typing is deterministic with no candidates to pick — but you have to know or reference the layout. The romanization keyboard uses the spelling you already know instead, no layout to memorize, but occasionally needs a candidate pick with the down arrow. Use whichever you're more comfortable with.

I typed something and got the wrong result — what happened?

Dubeolsik is a fixed key mapping, so the usual culprit is a missed Shift (the doubled consonants ㄲㄸㅃㅆㅉ and vowels ㅒㅖ all need Shift) or a misread key. Check the diagram above to confirm.

Can I use this dubeolsik keyboard on my phone?

Yes — tapping the text box brings up your phone's keyboard (still showing regular English letters), and tapping the matching key from the diagram above types the corresponding Korean letter. Since dubeolsik is a fixed mapping with no ambiguity, there's no candidate-picking involved.

Is there an app?

Not yet. You can add this page to your phone's home screen from your browser's menu, and it'll open with a tap, just like an app.

Why I built this

Dubeolsik is South Korea's official standard — the layout your keyboard turns into once you install a real Korean IME — but that doesn't help when you haven't installed one, or you're on a borrowed computer. This page runs on the same composition logic as the rest of the site, so anyone who already knows dubeolsik can type it without installing anything. If you don't know the layout yet, the romanization keyboard is probably the faster way in.
