用羅馬拼音打日文

打羅馬拼音，自動轉成日文假名。日文本來就有標準的羅馬字輸入規則，跟手機、電腦內建的日文輸入法一樣，不用另外學。

怎麼打

  1. 打羅馬拼音，例如 konnichiwa，會即時轉成假名，不會有候選字要選。
  2. ん：打 n。如果後面接的是母音，會先等一下看你要不要拼成別的音節， 例如 kinen 會變成「きねん」；如果就是要ん接母音，中間要加撇號隔開： kin'en 才會是「きんえん」。如果 n 是這個字打的最後一個字母，畫面上會先停在底線的 n，按空白鍵或 Enter 確定之後才會變成ん。
  3. っ（促音）：把下一個子音打兩次，例如 kekkon 是「けっこん」，只打一次 kekon 會變成「けこん」。
  4. 長音：母音連續打兩次會直接變成長音，例如 okaasan 是「おかあさん」； 片假名常用的長音記號可以直接打連字號 -，例如 ke-ki 打出「ケーキ」。
  5. 上面的按鈕可以隨時切換平假名／片假名的顯示，不影響你打的羅馬字。
  6. 打完按空白鍵或 Enter 確定，再複製貼到你要用的地方。

目前的限制

促音只認得「連續打兩個一樣的子音」，像「まっちゃ」要打 maccha 這種疊字寫法， 打 matcha 不會自動補上っ。輸入的內容只留在你的瀏覽器裡，不會被送到任何伺服器。

羅馬字對照表

し也可以打 si、ち也可以打 ti、つ也可以打 tu、ふ也可以打 hu；じ行也可以整行改打 zy 開頭（例如 zya），兩種拼法都收。

常見問題

日文鍵盤需要下載或安裝嗎？

不用。這是網頁版工具，打開就能打字，不用切換系統輸入法。

這跟手機、電腦內建的日文輸入法有什麼不同？

打法規則一樣，都是羅馬字轉假名。差別在於不用先在系統裡切換或啟用日文輸入法，臨時借用別人的電腦、或系統一時叫不出日文鍵盤的時候，打開網頁就能用。

ん要怎麼打？

打 n。如果後面接的是母音，系統會先等一下看你是要拼成別的音節，還是真的要ん接母音，例如 kinen 會變成きねん；如果要的是ん加母音，中間要打撇號隔開，kin'en 才會是きんえん。如果 n 是這個字打的最後一個字母，畫面上會先停在底線的 n，按空白鍵或 Enter 確定之後才會變成ん。

促音（っ）要怎麼打？

把下一個子音打兩次，kekkon 是けっこん，只打一次 kekon 會變成けこん。目前只認得「連續打兩個一樣的子音」這種寫法，まっちゃ要打成 maccha，打 matcha 不會自動補上っ。

平假名跟片假名切換，會不會影響我已經打好的字？

不會。上面的按鈕只是切換顯示，不會動到你打的羅馬字或已經確定的內容，可以隨時切換。

為什麼做這個工具

手機、電腦雖然本來就有內建的羅馬字輸入法，但不是每次都能馬上叫得出來，例如只是想臨時打幾個字。這個工具沿用同一套引擎邏輯，做成了日文版本。希望這一套線上日文鍵盤能幫助初學者更快上手日文輸入，也能讓不常打日文的人偶爾需要時不用再去安裝輸入法。
