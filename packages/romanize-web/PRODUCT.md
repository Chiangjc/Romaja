# romanize.latype.com

外文轉羅馬拼音的獨立網站，跟 latype.com 的輸入法分開部署（Cloudflare 專案 `latype-romanize`）。

## 定位

- 主打學習：還不會讀原文的人，把外文貼進來，照實際發音轉成羅馬拼音，跟著念、練發音。介面文案（標題、副標、使用說明）以學習為主軸。
- 歌詞是輔助：用來宣傳和帶 SEO 流量。只出現在 meta description 的例子（課文、例句、歌詞）和每個語言頁的歌詞 FAQ 裡，不當標題或副標。逐行對照、音節加 `-` 是給所有練習用的，選項名稱不寫「歌詞用」。
- 方向跟輸入法相反（原文 → 羅馬字），所以兩個站互相連結，但各自有自己的頁面與 sitemap。

## 跟輸入法不同的原則

輸入法的「核心不依賴詞表」（claude.md 第 13 節）不適用這個站。日文漢字讀音、中文多音字、粵語讀音都必須靠詞典才轉得出來。這裡的規則是：

- 可以用詞典，但只能在瀏覽器端執行，沒有後端。使用者的文字不離開瀏覽器。
- 詞典只在需要的語言頁按需載入，不拖慢其他頁面。
- 能用純規則做的語言（韓文）就用純規則。

## 各語言的做法

- **韓文**：`@romanization/engine` 的 `hangulToPronunciation`，純規則。
- **普通話**：`packages/romanize-zh`。讀音用 pinyin-pro（MIT）的詞表判斷多音字。它的詞表是簡體，繁體直接查會讀錯（們 → mén、還是 → huán shì），所以先用 opencc-js（`t2cn`，tw → cn，只換字形）轉成簡體再查。兩個函式庫加起來幾百 KB，頁面載入後才用 dynamic import 載進來。讀音照台灣標準（教育部《國語辭典》）：pinyin-pro 照大陸標準，查完再用 `romanize-zh/src/taiwan.ts` 改。兩岸讀音不同的常見字詞（垃圾 lè sè、星期 xīng qí、認識 rèn shì）列在對照表裡；輕聲只留給虛詞、詞尾和親屬疊字（朋友 péng yǒu、媽媽 mā ma），其他字還原本調。對照表只收常見詞，冷門字詞可能仍是大陸念法，遇到再補。
- **日文**：`packages/romanize-ja`。漢字讀音用 kuromoji（`@sglkc/kuromoji`，Apache-2.0，IPADIC 詞典）做形態素分析，再照平文式轉羅馬字。助詞照念法（は wa、へ e、を o）；助動詞、て形黏回動詞（ikitai、nonde），助詞分開。長音可選照假名（arigatou）或長音符號（arigatō，えい 保留成 ei）。詞典壓縮後約 17 MB，`scripts/copy-ja-dict.mjs` 在 dev／build 前複製到 `public/dict/ja/`（不進 git），使用者開始互動才下載。
- **泰文**：`packages/romanize-th`，照皇家泰語通用轉寫系統（RTGS）。切詞用瀏覽器內建的 `Intl.Segmenter`（ICU 泰文詞典），不用另外下載。每個詞再用動態規劃切音節：列出每個位置所有合法的音節形狀（前置母音、複輔音、假複輔音、ห／อ 帶頭、前導子音、隱含母音、不發音的 ์），寫出來的母音代價最低、隱含 o 次之、隱含 a 最貴。規則推不出來的常用詞（巴利梵語借詞，如 ผลไม้ phon-la-mai、บริษัท bo-ri-sat）放在 `romanize-th/src/exceptions.ts`，在動態規劃裡也算一種切法，所以複合詞裡也會套用。RTGS 不標聲調、不分長短音。音節預設用連字號隔開（sa-wat-di），可切換成連寫（sawatdi）。

## 導覽

latype.com（打字）跟 romanize.latype.com（轉換）用同一套導覽，兩個站對使用者來說像同一個網站：

- **頁首**：每一頁都一樣，語言分頁照 韓文、日文、中文、泰文 排。換語言時如果那個語言在目前這個站也有工具，就留在同一個站（在打字的繼續打字、在轉換的繼續轉換），沒有才跳到另一個站。
- **⇄ 方向切換列**：放在 h1 上面，左邊是輸入、右邊是輸出（韓文 ⇄ 羅馬拼音），⇄ 連到反方向的工具，兩頁之間可以原地來回連按。韓文打字頁左邊那一格可以直接換輸入法（羅馬拼音／두벌식）。只有轉換頁的語言（中文、泰文）不顯示。
- 兩者都由 `packages/site-nav/index.mjs` 的工具清單在 Vite 建置時產生（HTML 裡的 `<!--site-header-->`、`<!--direction-switch-->`）。加語言或工具只改那份清單；開發時跨站連結指到本機的 5173／5174。

## 網址

- `/`、`/en/`：語言清單
- `/ko/`、`/en/ko/`：韓文
- `/zh/`、`/en/zh/`：普通話（漢語拼音）
- `/ja/`、`/en/ja/`：日文（平文式羅馬字）
- `/th/`、`/en/th/`：泰文（RTGS）
- 之後的語言照同樣的格式加：`/yue/`

latype.com 的舊網址 `/romanize/`、`/en/romanize/` 用 `packages/web/public/_redirects` 301 轉過來。
